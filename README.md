# Train-weigh
разберем как  обучать хотя бы один вес на простом скрипте это сделано для новичков такшто скрипт будет простой.
Если вы новичок в ии или чучуть знаете язык программирования пайтон и хотите создавать свой ИИ то вам сюда потому что  обычно сначала надо понять основы чтоб потом самому скриптить такие коды. 
```Python
# тут находится x то есть входы
x1 = 2
x2 = 3
x3 = 2.5
# тут находятся y то есть правильные ответы на входы
y1 = 3
y2 = 4
y3 = 6
# это один вес чтобы очень просто понять суть
w1 = 0.8
# это  количество на сколько он изменяет как ниже будет показано  он умножается на ошибку под названием losse
lr = 0.05
for i in range(0, 100):
# это z то есть ошибка определенного x чтоб его правильно исправить   
    z1 = w1 * x1 - y1
    z2 = w1 * x2 - y2
    z3 = w1 * x3 - y3
# это ошибка там складывается общая ошибка и делится на их количество
    losse = (z1 + z2 + z3) / 3
# тут мы изменяем вес на lr умноженное на ошибку
    w1 = w1 - (lr * losse)
    print(w1)
```
надеюсь вы прочитали всё в скрипте и можете понять что  и как работает. Ну а на этом все всем удачи в дальнейшем.
